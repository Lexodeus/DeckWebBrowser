# Changelog

## 1.4.3-3 (2026-10-18)

- The Menu Position setting now lists the Steam menu's own entries ("3: above Store"), including other plugins' entries, and skips entries a theme hides.

### Fixes

- The browser works again on Decky Loader 3.3.0, where its settings, favourites and history stopped loading.
- The Browser entry lands in the right place alongside Spotify and Discord with themes that hide menu entries, wherever it's placed.

## 1.4.3-2 (2026-10-16)

### Fixes

- The Browser, Spotify and Discord entries in the Steam menu now always appear in the same order, so CSS Loader themes that hide menu entries (like Main Menu Hide Tabs) hide the right one.
- Reloading the Web Browser plugin no longer removes other plugins' entries from the Steam menu.

## 1.4.3-1 (2026-10-16)

### Fixes

- The Browser entry in the Steam menu now stays in the position you chose, even when games are running.
- The top of the screen no longer turns into a black bar of error text after opening the browser on the latest SteamOS, and the browser's address bar works again.
- Tapping a text box that a page has already selected, like Google's search box, now brings up the on-screen keyboard.
- The on-screen keyboard is no longer hidden behind web pages when using a keyboard theme such as CSS Loader's Transparent Keyboard.
